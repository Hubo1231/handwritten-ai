# Policy Gradient — REINFORCE

从零手写实现的 **REINFORCE** 算法（蒙特卡洛策略梯度，Williams 1992），
策略梯度方法家族中最基础的算法。

## 📂 文件说明

| 文件 | 说明 |
| --- | --- |
| `reinforce.py` | 核心实现：策略网络、动作采样、折扣回报计算、策略更新、训练循环 |
| `example.py`   | 最简使用示例：训练 + 评估，开箱即用 |

## 🧮 算法原理

策略梯度方法**直接参数化策略** π_θ(a\|s)，通过梯度上升最大化期望回报 J(θ)。

利用策略梯度定理 + 对数求导技巧，并用 **reward-to-go**（从当前时刻往后的
折扣回报 G_t）替换整条轨迹回报以降低方差：

```
∇_θ J(θ) = E[ Σ_t ∇_θ log π_θ(a_t|s_t) · G_t ]
G_t      = r_t + γ·r_{t+1} + γ²·r_{t+2} + ...
```

由于 PyTorch 优化器做的是梯度**下降**，我们构造一个伪损失
（对其最小化 ⇔ 对 J 最大化）：

```
L(θ) = - Σ_t log π_θ(a_t|s_t) · G_t
```

**降低方差的技巧**：本实现对每个 episode 的回报做标准化（零均值、单位方差），
相当于使用一个简单的 baseline，使训练更稳定。

## 🚀 快速开始

```bash
# 安装依赖
pip install torch gymnasium numpy

# 方式一：直接运行训练脚本（带命令行参数）
python reinforce.py --episodes 600 --lr 1e-2 --gamma 0.99

# 方式二：运行最简示例（训练 + 评估）
python example.py
```

CartPole-v1 通常在数百个 episode 内即可达到平均回报 475+（视为“解决”）。

## ⚙️ 主要超参数

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `--gamma` | 折扣因子 γ | 0.99 |
| `--lr`    | 学习率 | 1e-2 |
| `--hidden`| 隐藏层宽度 | 128 |
| `--episodes` | 训练 episode 数 | 600 |
| `--solved` | 提前停止的平均回报阈值 | 475 |

## 📌 REINFORCE 的特点与局限

- ✅ 简单直观，是理解策略梯度的最佳入门；可直接处理连续/高维动作（换用相应分布）。
- ⚠️ **方差大**：基于整条轨迹的蒙特卡洛估计，梯度噪声大、收敛慢。
- ⚠️ **样本效率低**：每条轨迹只用一次（on-policy），用完即弃。

后续的 Actor-Critic、A2C/A3C、PPO 等正是为了缓解这些问题而提出的。
